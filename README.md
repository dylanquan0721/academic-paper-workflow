# Academic Paper Workflow · 论文与文献助手

在 Codex 聊天中完成文献检索、证据整理、论文起草和引用核验的 skill。适合需要在一个学期内持续推进多门课程论文的人，也可用于单篇论文的相关工作。

## 原项目与作者署名

本项目的流程设计受到 **[mmlong818](https://github.com/mmlong818)** 创建的 **[Open Academic Paper Gen](https://github.com/mmlong818/open-academic-paper-gen)** 启发。感谢原作者在多源文献检索、证据表、分节写作和引用核验方面的工作。

这是重新编写的聊天版工作流，不是原作者发布的官方 skill，也不代表原作者认可或参与了本项目。本仓库不包含原项目的 Python/前端代码，不运行其 LangGraph 流水线。原项目采用 [AGPL-3.0](https://github.com/mmlong818/open-academic-paper-gen/blob/main/LICENSE)；其代码和文档的权利归原权利人所有。本仓库新增的工作流说明采用 [MIT License](LICENSE)。

## 改造了什么

| 原项目的思路 | 聊天版的实现 |
| --- | --- |
| 多源检索与文献筛选 | 使用当前聊天可用的搜索工具，记录真实查询与筛选理由 |
| 文献证据表 | 用稳定来源 ID 关联研究方法、结果、局限、原文位置和拟支持的论点 |
| 选题、提纲与分节写作 | 结合课程要求、评分标准和已有草稿，只执行本次需要的阶段 |
| 三层引用核验 | 分别检查引用能否对应、文献是否存在、原文是否支持具体论点 |
| 流程状态保存 | 在当前项目里保存必要的检索记录、证据表和后续工作说明 |

不需要启动数据库、网页服务或另外配置模型 API 密钥；搜索和文件访问能力取决于当前 Codex 环境。skill 本身是给助手的工作指导，不是独立搜索引擎，也不会自动获得付费数据库或学校订阅的访问权。

## 安装

把本仓库链接交给 Codex，并说明：

> 请使用 skill-installer，从这个仓库安装 skills/academic-paper-workflow。

也可以下载仓库，把 `skills/academic-paper-workflow` 整个文件夹复制到自己的 Codex skills 目录：默认是 `~/.codex/skills/`；如果设置了 `CODEX_HOME`，则为该目录下的 `skills/`。避免覆盖已有的同名自定义版本。

## 使用

在聊天里明确调用 `$academic-paper-workflow`，再说明项目目录和这次要完成的任务。普通论文与文献请求也可由 Codex 自动选择该 skill。

示例：

- “用 $academic-paper-workflow，读取当前课程的作业要求，帮我把研究问题缩小到可写的范围。”
- “找与这个研究问题相关的实证论文，整理证据表，标出哪些读到了全文、哪些只有摘要。”
- “根据这些已核验的文献写相关工作，保留我的观点，并标出还缺证据的地方。”
- “检查这篇草稿的引用：先核对文献是否存在，再逐句判断它是否支持我写的论点。”
- “继续这个项目，先读取上次保存的研究记录，再推进未完成的部分。”

第一次使用时，提供或指出课程作业要求、评分标准、草稿位置，以及题目或研究方向即可。字数、语言、引用格式和截止日期若已写在作业要求里，不必重复填写。资料分散时，先指定本次课程目录，避免混用不同课程的要求。

长期项目可按实际需要保存检索日志、文献证据表和简短进度记录。skill 不会自动扫描所有文件、监控文件变化或记住全部历史聊天；继续任务时依靠当前文件和项目记录恢复上下文。

## 核验结果怎么看

“文献存在”不等于“文献支持这句话”。同一来源的元数据核验和论点支持判断会分别记录。无法打开全文时会说明证据范围；网络错误不会被记作核验通过，也不会直接被当作文献虚假。

引用支持状态包括：支持、部分支持、矛盾、不明确、未核验。结论会附原文位置或判断依据。生成内容需要结合真实来源和课程要求复核；不会虚构实验、数据、引文或检索过程。
